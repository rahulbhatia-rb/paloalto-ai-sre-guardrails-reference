# AI-SRE Remediation Guardrails

Application reference for Palo Alto Networks’ Staff AI-SRE role. The tested policy permits automated remediation only when a change is approved, the diagnostic confidence is high, the blast radius is bounded, and the service has sufficient error budget. Otherwise it proposes a reviewed action or protects reliability through escalation.

This demonstrates an AI-assisted operational control loop for Kubernetes, Terraform, AIOps, LLM-based diagnostics, and incident response without claiming access to Palo Alto Networks systems.
